## Objectives
- A reference point for my online presence.
- A way to make my professional profile stand out.
- A place to share ideas.

## Stack
I built this website with Quartz v5, hosted on GitHub Pages.

| Pros                                                                                                                   | Cons                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Static site generator based on Markdown: my content stays readable and independent of the tool.                        | Actively maintained mainly by one person, although backed by a larger community.             |
| Obsidian-like appearance out of the box.                                                                               | v5 has many nice features but also many bugs, which I contribute back to as bug reports.     |
| A chance to learn [[TypeScript from Python.canvas\|TypeScript]] and [[CSS Learning.canvas\|CSS]] step by step.         |                                                                                              |

GitHub Pages is free, and deploying is straightforward by following the example in the Quartz v5 docs. The source code of this website is publicly available.

## Learning
When I started this project, I knew nothing about building websites. The key concepts I picked up:
- **Static site generators (SSGs)** build a website as pre-generated HTML files from content and templates (e.g. Jekyll, Hugo, Quartz). They are ideal for content-focused sites.
- **GitHub Pages** serves those static files directly from a repository.
- **Quartz v5** is built on:
	- [[TypeScript from Python.canvas|TypeScript]], for the logic and plugins;
	- [[CSS Learning.canvas|CSS]], for the styling.

Source: [roadmap.sh](https://roadmap.sh/frontend)
